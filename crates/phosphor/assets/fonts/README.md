# Fonts

## vga_8x16.bin

The IBM VGA 8x16 text-mode font, in CP437 order: 256 glyphs x 16 bytes, one
byte per scan line with the most significant bit leftmost.

Extracted from the `int10_font_16` table in `src/ints/int10_memory.cpp` of
