Extras

Themes and bezels

More colors for BadTerm's screens and more monitors to put them in. Download one, bring it in, and it's in the list in Settings. Made one you like? Share it.

Color themes

Themes

To use one: download it, then in BadTerm open Settings (Alt-O), Colors, "Import a theme", and give it the file.

Monitor bezels

Bezels

To use one: download it into BadTerm's bezels folder (badterm --paths shows where), then choose it in Settings, Display, "Monitor bezel".

Share yours

Add to the collection

These files live in the extras folder of BadTerm's repository, and the page is made from it.

  • A theme: set up your colors in Settings, then "Save as a theme". Add a description line to the file and put it in extras/themes.
  • A bezel: a PNG of a monitor whose screen area is see-through, in extras/bezels, with a few lines about it in bezels.toml. Your own art only, please, and no makers' names or logos.

Then send a pull request, or bring the file to The Vortex BBS. The folder's README has the details.
